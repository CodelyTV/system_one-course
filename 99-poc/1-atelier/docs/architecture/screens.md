# Architecture: Screens

- `/` — Catalog: product cards, prices, badges and a collection filter.
- `/products/[id]` — Product detail: variants (color/size), online stock and add to cart.
- `/checkout` — Checkout: cart summary, home delivery and order confirmation.
- `/account` — Account: the current user's orders.
- `/admin` — Admin: operational overview metrics, inventory and orders.
